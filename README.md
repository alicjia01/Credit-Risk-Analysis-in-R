# Credit Risk Analysis in R

## Project Overview
This project focuses on analyzing credit risk using real-world financial and demographic data.
The goal is to explore which factors are associated with a higher probability of financial distress
and to build an interpretable statistical model based on these variables.

The project was completed as a **final assignment for a university data analysis course** and was fully
implemented in **R**.

## Research Objective
The main objective of the project is to:
- analyze relationships between customer characteristics and credit risk,
- identify key predictors of financial difficulties,
- apply statistical modeling techniques to assess default risk.

## Data
- **Dataset:** Credit-related customer data  
- **Source:** Kaggle  
- **Type:** Customer-level financial and demographic data  

The dataset includes a detailed **data dictionary** describing each variable and its meaning.

### Example Variables
- Age  
- Monthly income  
- Number of dependents  
- Debt ratio  
- Past-due payment history  
- Indicators of financial distress  

## Methodology
The analysis was conducted in **R** and includes:
- Data cleaning and handling of missing values  
- Exploratory data analysis (EDA)  
- Visualization of key variables and relationships  
- Statistical modeling for credit risk assessment  

## Files in This Repository
- `project.R` – main R script containing data preparation, analysis, and modeling  
- `Final_raport.pdf` – final written report describing methodology and results  
- `cs-training.csv` – dataset used in the analysis  
- `Data Dictionary.xls` – description of variables included in the dataset  

## Libraries Used
- tidyverse  
- ggplot2  
- dplyr  
- car  
- psych  

## Key Findings
The analysis shows that credit risk is influenced by a combination of financial and demographic factors.
The results highlight the importance of responsible data preprocessing and careful interpretation of
statistical models in financial decision-making.
